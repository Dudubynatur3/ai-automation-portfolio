# Workflow Evidence Policy for This Project

The complete reusable n8n export for this project is intentionally not included on the current public branch.

The portfolio evidence is designed to make the engineering inspectable without providing a copy-and-deploy package.

Public evidence for this workflow includes:

- system architecture
- deterministic routing rules
- persisted data contract
- five tested routing outcomes
- downstream Google Sheets and Gmail behaviour
- reliability and implementation decisions

For intentionally open demo projects, a full importable workflow may still be published. This project is not treated as that type of demo.
