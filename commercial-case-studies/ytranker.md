# YTRanker SaaS Platform Engineering

**Classification:** Commercial production experience  
**Period:** March 2026 to July 2026  
**Source code:** Private, intentionally not published

## Context

YTRanker is a production SaaS platform coordinating video-production and operational workflows across multiple user roles.

My work is represented here as a case study because publishing private production source code would be inappropriate. The evidence focuses on scope, systems, validation, and handover.

## Engineering scope

Worked across a platform involving:

- React
- Supabase
- Vercel
- GitHub
- Gmail OAuth
- Telegram
- WhatsApp
- OpenRouter
- Anthropic
- external APIs

The platform had previously used Netlify and later operated with Vercel and Supabase as the production architecture.

## Responsibilities and delivery

### AI provider migration

Supported migration of AI functionality from Anthropic-based configuration to OpenRouter and validated application behaviour after the change.

### Integrations

Worked with messaging, email authentication, AI-provider, and external API integrations, including Gmail OAuth, Telegram, and WhatsApp-related functionality.

### Operational workflow controls

Implemented and validated functionality involving:

- role-based permissions
- task assignment
- deadlines
- payment / finance workflow controls
- client publishing guards
- operational workflow behaviour

### Troubleshooting

Investigated issues spanning application behaviour, permissions, authentication, Supabase configuration, integrations, and deployment.

### Regression validation

Before handover:

- regression tested across **6 user roles**
- validated **40+ feature branches**

### Technical handover

Produced comprehensive technical handover material covering architecture, deployments, integrations, security considerations, configuration, and operational continuity.

## Why this evidence is different from the portfolio projects

The other projects in this repository demonstrate independent workflow engineering or structured training implementations.

YTRanker demonstrates commercial ownership and production delivery. It therefore carries stronger operational evidence, but the source code remains private.
